Why FinShield

Clarity for two everyday risks.

Personal finance can be complicated. Fraud messages can be convincing. FinShield turns common warning signs into practical, understandable steps.

Academic project · 2026

Built to make financial safety more approachable.

FinShield is an educational MVP for an Information and Communication Technologies course. It combines a transparent credit-burden estimate with rule-based awareness of common social-engineering patterns. It is not a financial institution, credit bureau, or security service.
